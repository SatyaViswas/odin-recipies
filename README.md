# odin-recipies
**🍽️ Basic Recipes Website**

This is a simple HTML project built as part of The Odin Project - Foundations Course.
The goal of this assignment was to practice basic HTML structure, linking pages, and working with text and images to create a small recipe website.

**📚 What This Project Includes**

A main index page that lists available recipes.

Individual recipe pages, each containing:

A title and short description

List of ingredients

Step-by-step cooking instructions

An image representing the dish (if included)

**🧩 Skills Demonstrated**

Basic HTML markup

Structuring pages using headings, paragraphs, lists, and links

Creating multiple pages and linking them together

Using images in HTML (<img> tag)

Organizing project files into folders

**🎯 Learning Reflection**

This project helped me get comfortable with:

Writing clean and semantic HTML.

Linking multiple HTML files together.

Understanding the importance of structure when building websites.

It’s a very simple project, but it marks the starting point of my web development journey! 🌱
